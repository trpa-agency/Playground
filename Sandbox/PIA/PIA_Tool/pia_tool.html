⚠️ TRPA Project Impact Assessment Tool — Terms of Use

Welcome to the TRPA Project Impact Assessment (PIA) Tool. This tool provides initial screening and VMT analysis for projects within the Lake Tahoe Region.

How to use:
1) Select your proposed project type.
2) Click the map to select your project's PIA Zone.
3) Enter the project size.
4) Optionally select mitigation strategies.
5) Click Calculate VMT to see results.

Disclaimer: This tool is provided "AS IS" without warranty. Results are preliminary only and must be verified with TRPA staff before formal submission. TRPA shall have no liability for any losses arising from use of this tool.
